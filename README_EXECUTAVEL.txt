ALFRED - VERSÃO PARA WINDOWS
============================

1. Coloque ALFRED.exe em uma pasta no computador de destino.
2. Copie .env.example para um novo arquivo chamado .env.
3. Abra o .env e substitua o valor de OPENAI_API_KEY por uma chave nova da OpenAI.
4. Verifique se o computador possui microfone, alto-falante e acesso à internet.
5. Execute ALFRED.exe.

MODOS DE MODELO:
- "Alfred, use o modo econômico" prioriza Luna.
- "Alfred, use o modo normal" usa Terra como professor padrão.
- "Alfred, use o modo avançado" permite Sol em tarefas realmente complexas.
- "Alfred, use Sol nesta pergunta" força Sol somente uma vez.

MATERIAIS:
Coloque arquivos PDF, TXT, MD ou DOCX em study\materials.
Coloque provas em study\exams. As anotações pedidas por voz ficam em study\notes.

Exemplo do arquivo .env:
OPENAI_API_KEY=sua_chave_nova_aqui

IMPORTANTE:
- Não envie seu arquivo .env para outras pessoas.
- O uso da API OpenAI depende da conta associada à chave configurada.
- A primeira abertura do executável pode demorar alguns segundos.
