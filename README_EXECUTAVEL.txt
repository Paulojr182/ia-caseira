ALFRED - VERSÃO PARA WINDOWS
============================

1. Coloque ALFRED.exe em uma pasta no computador de destino.
2. Copie .env.example para um novo arquivo chamado .env.
3. Abra o .env e substitua "coloque_sua_chave_aqui" pela chave da API Gemini.
4. Verifique se o computador possui microfone, alto-falante e acesso à internet.
5. Execute ALFRED.exe.

Exemplo do arquivo .env:
GEMINI_API_KEY=sua_chave_aqui

IMPORTANTE:
- Não envie seu arquivo .env para outras pessoas.
- O uso da API Gemini depende da conta associada à chave configurada.
- A primeira abertura do executável pode demorar alguns segundos.
